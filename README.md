# Tailscale mini на клиентском OpenWrt

Текущий установщик `tailscale-router-install.sh` (также сохранён как `tailscale-router-mini.sh`) использует [GuNanOvO/openwrt-tailscale](https://github.com/GuNanOvO/openwrt-tailscale). Это сторонняя сборка Tailscale из указанного пользователем источника.

## Запуск

Подключитесь к роутеру через локальный SSH и выполните:

```sh
wget -O /tmp/tailscale-mini.sh 'https://raw.githubusercontent.com/TMN88/TS_client_install/main/tailscale-router-mini.sh' &&
sh /tmp/tailscale-mini.sh
```

Скрипт скачивает `install_en.sh` в `/usr/sbin/install.sh` и вызывает:

```sh
/usr/sbin/install.sh --persistent-install --yes
```

Выбран постоянный режим установки пакета из feed этого проекта. Временная установка в `/tmp` и автоматические обновления по cron не включаются. Обновление прошивки не выполняется. Установщик источника сам выбирает пакет для архитектуры роутера и проверяет загружаемый пакет по опубликованной им контрольной сумме.

После установки применяются настройки исходного пользовательского скрипта: userspace networking, SOCKS5 на `0.0.0.0:1055`, постоянный state-файл `/etc/tailscale/tailscaled.state`, отключённые DNS/маршруты Tailscale и управление netfilter. SOCKS5 доступен на всех IPv4-интерфейсах, насколько разрешает firewall. Стандартный пакет из репозитория OpenWrt не используется как запасной источник.

## Авторизация

Для нового устройства установщик покажет ссылку. Откройте её на компьютере или телефоне, войдите в нужный аккаунт Tailscale и подтвердите подключение роутера. Установщик ждёт до 5 минут. Auth key не используется.

При ошибке входа установщик завершится с кодом 2. Смена сборки сама по себе не гарантирует устранение проблем связи с сервером управления. Установка предыдущей версии на тестовом роутере завершилась состоянием Running; новая итоговая проверка пока проверена только локально с имитацией роутера.

## Итоговый отчёт

В конце установки, включая ошибочное завершение после начала работы, выводится блок «ИТОГ УСТАНОВКИ TS MINI». Заголовок выделен ярким бирюзовым цветом, успешные проверки — ярким зелёным, ошибки — красным, недоступные проверки — жёлтым. Для отключения ANSI-цветов задайте `NO_COLOR=1 sh /tmp/tailscale-mini.sh`.

Проверяются установленная версия TS mini, наличие процесса, фактический аргумент userspace у процесса, состояние Running, Tailscale IPv4, автозапуск, непустой state-файл и содержимое/синтаксис/право выполнения hotplug для WAN/WAN6. Через `tailscale debug prefs` дополнительно проверяются отключённые DNS, netfilter и приём маршрутов. Если debug prefs недоступен в сборке, отчёт явно укажет это, не выдавая непроверенные настройки за подтверждённые.

Итоговое SUCCESS появляется только при нулевом коде установки и прохождении обязательных проверок. Ошибка обязательной итоговой проверки даёт ненулевой код завершения. Отчёт читает состояние и не запускает дополнительный перезапуск Tailscale. Автоматическое срабатывание hotplug при реальном событии WAN, удалённый SSH, отсутствие Ephemeral и работа после перезагрузки требуют отдельной проверки.

## Автозапуск и восстановление

Автозапуск включён. Hook исходного скрипта принудительно перезапускает Tailscale на каждом событии `ifup` интерфейсов `wan` и `wan6`, без задержки. Hook создаётся до начала браузерного входа.

Удаление устройства, logout и сброс идентичности в наш скрипт не добавлены. Существующая регистрация сохраняется. Перед вызовом установщика источника прежние файлы конфигурации, службы и hook копируются в `/etc/tailscale/mini-backup-XXXXXX`; путь печатается в выводе. Это копия конфигурации, не автоматический откат пакета. Идентичность и конфигурационные копии не публикуйте.

## Проверка

После подключения проверьте, что в панели Tailscale нет метки Ephemeral, и выполните с другого устройства tailnet:

```sh
ssh root@100.x.x.x
```

Используйте адрес, выданный новым подключением. Затем при наличии локального доступа проверьте восстановление SSH после перезагрузки. Установка перезапускает службу и временно обрывает существующее соединение Tailscale.

`tailscale-router-original.sh` остаётся неизменённой копией исходного пользовательского скрипта с обычным `apk add tailscale`; это архивный вариант, не TS mini.
